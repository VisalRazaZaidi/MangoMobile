# Security and data safety

MangoMobile can permanently remove files from an attached Android device. Review cleanup previews and keep backups of files you cannot replace. Moving files to the recycle bin retains them on the phone until they are purged, including automatic retention expiry.

Download Windows builds only from this repository's GitHub Releases and compare their SHA-256 hashes with `SHA256SUMS.txt`. Current binaries are unsigned.

Please report vulnerabilities privately through this repository's Security tab if private reporting is available. Otherwise open an issue describing the affected component and a way to contact you, without including exploit details or private file contents.
